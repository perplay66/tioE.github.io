TREINO DO ANIVERSARIANTE — ELIAQUIM

Arquivos
- index.html: site completo em um único arquivo.

Atualizações desta versão
- Animações articuladas e específicas para supino, agachamento e puxada alta.
- Ciclos de movimento sincronizados com as cinco repetições de cada exercício.
- Tela de conclusão com botão “REVELAR MINHA SURPRESA”; a página de aniversário não abre automaticamente.
- Botão de pular treino continua disponível.
- Respeita a preferência do dispositivo por movimento reduzido.

Personalização posterior
- Mensagem: edite o conteúdo do elemento com id="birthdayMessage" no index.html.
- Foto: coloque a imagem na pasta e configure o elemento img com id="finalImage" (src="nome-da-foto.jpg"); para exibi-la, remova display:none do CSS de .final-photo img.
- Música: coloque o arquivo na pasta e configure src do elemento audio com id="birthdayAudio".

Publicação
Envie a pasta para um repositório GitHub e ative GitHub Pages usando a branch principal e a pasta raiz.
